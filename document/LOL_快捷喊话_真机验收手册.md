# 快捷喊话子系统 — 真机验收手册

> 前置：已按 `LOL_快捷喊话_设计规格_v1.0.md` 完成开发，离线验证全绿
> （384 pytest + ruff + offscreen 冒烟）。
> 本手册用于**国服训练模式真机验收**。铁律：**进游戏后除验收动作外什么都别按**
> （手动开过聊天框会导致 Enter 序列错位，这是历史踩坑）。

## 0. 准备

1. 启动 Seraphine（`python main.py` 或打包版），导航栏应出现「快捷喊话」页。
2. 进入该页：确认内置 5 个分组（对线/打野/团战/资源/礼貌）各 5 条话术已就位。
3. 打开「Enable quick chat」总开关。
4. 启动 LOL 客户端，开一局**训练模式**（自定义 → 训练 → 单人）。

## 1. 局内直发（核心）

- [ ] 进入对局后按 `Alt+1` → 聊天框自动弹出、输入、发出「对线」组第 1 条。
- [ ] 连续按 20 次（间隔 >1s，轮流 Alt+1~5）→ 成功率 ≥ 95%（19/20）。
      失败判定以**游戏内聊天记录**为准，不看工具侧提示。

## 2. 组内循环（D11）

- [ ] 连按 5 次 `Alt+1` → 依次发出「对线」组第 1~5 条；第 6 次回到第 1 条。
- [ ] 设置页该分组「Next in cycle」预览与实际发出的下一条一致。

## 3. 双通道（LCU）

- [ ] 开一局排位的 BP 阶段（或自定义房间选人）按 `Alt+1` → 消息出现在 **BP 聊天框**。
- [ ] 房间（Lobby）未开始匹配时按热键 → 消息出现在房间聊天。
      （若 Lobby 不发，查看日志 `sendChatMessage: no conversation ... available=[...]`，
      把 available 类型反馈给开发侧调整 `_CONV_TYPES_BY_PHASE`。）

## 4. 闸拦截

- [ ] 游戏切到后台（Alt+Tab 到桌面）按热键 → 无反应。
- [ ] 客户端大厅（非 BP/房间/局内）按热键 → 无反应。
- [ ] 关闭总开关后按热键 → 无反应。

## 5. 热键冲突硬拦截

- [ ] 设置页把某分组热键改为 `Alt+Q` 保存 → 被拒绝并提示；改为 `Alt+6` → 保存成功。
- [ ] 把两个分组绑同一键 → 第二次保存被拒绝。

## 6. 发送日志

- [ ] 设置页「Send log」点 Refresh → 每条发送有时间/文本/通道(ingame|lcu)/结果。

## 7. 发送方式（可选）

- [ ] 打开「Paste whole message via clipboard」→ 局内发一条 >20 字话术 → 正常发出，
      且 800ms 后原剪贴板内容被还原（期间不要自己复制东西）。

## 8. 重启持久化

- [ ] 重启 Seraphine → 自定义话术/分组/改绑热键保留；循环游标保留。
